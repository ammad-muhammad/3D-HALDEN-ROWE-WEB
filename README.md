# 3D Halden Rowe Web

An immersive 3D interactive luxury tailoring and bespoke menswear web experience built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features

- **Cinematic 3D Scroll Storytelling**: Seamless multi-sequence frame animations synced with user scroll.
- **Product Showcase**: Tailored suits, jackets, and luxury apparel collection with interactive previews.
- **Modern Responsive Design**: Smooth transitions, glassmorphic UI, and bespoke typography.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
